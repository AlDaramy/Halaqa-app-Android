# تطبيق متابعة حلقات القرآن الكريم — نسخة Android (الإصدار 2)

## الفكرة
التطبيق على الجوال يفتح **نسخة الويب** من مستودعك (GitHub Pages)، ويحفظها للعمل بدون إنترنت.
فأي تعديل ترفعه على المستودع يصل للتطبيق **عند فتحه** بدون تثبيت أي ملف جديد.

## أول مرة
1. ارفع محتويات هذا المجلد (ومعها `.github`) على مستودعك.
2. فعّل الصفحات: **Settings ← Pages ← Source: GitHub Actions**.
3. تأكد أن **Settings ← Actions ← General ← Workflow permissions** على **Read and write permissions**.
4. افتح **Actions** وانتظر نجاح التشغيل ✅ (يعمل Job باسم `pages` وJob باسم `android`).
5. افتح قسم **Releases** في المستودع وحمّل `Halaqa-Android-2.0.X.apk` وثبّته على الجوال.
6. افتح التطبيق **مرة واحدة وأنت متصل بالإنترنت** ليحفظ نفسه، ثم يعمل بدونه.

## بعد ذلك
- **تعديل التطبيق** (الشكل والمزايا): ارفع الملف على المستودع فقط. بعد اكتمال **Actions** يصل التعديل للتطبيق عند فتحه.
  لا حاجة لتثبيت APK جديد.
- ملف APK نفسه يحتاج تثبيتًا جديدًا فقط لو غيّرنا شيئًا في أندرويد نفسه (الأيقونة أو الصلاحيات).
- رقم الإصدار: الرقمان الأولان من `version` في `package.json` والثالث رقم البناء تلقائيًا.

## مهم
- **البيانات تُحفظ داخل التطبيق** ولا تنتقل من النسخة القديمة. قبل التثبيت: **الإعدادات ← تصدير البيانات**، وبعده: **استرجاع نسخة**.
- لو ثبّتت APK جديدًا فوق القديم ورفض الجهاز، احذف القديم أولًا (بعد النسخة الاحتياطية).
