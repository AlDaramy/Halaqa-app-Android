# تطبيق متابعة حلقات القرآن الكريم — نسخة Android

1. أنشئ مستودعًا جديدًا على GitHub وارفع **كل محتويات هذا المجلد** (ومعها المجلد المخفي `.github`) على الفرع `main`.
2. افتح تبويب **Actions** ← انتظر نجاح **Build Android app** ✅ (نحو 3 دقائق).
3. افتح التشغيل الناجح، وانزل إلى **Artifacts**، وحمّل `Halaqa-Android` ثم فك الضغط.
4. انقل `app-debug.apk` إلى الموبايل وافتحه، واسمح بالتثبيت من هذا المصدر.
   لو ظهر تحذير Play Protect: **Install anyway**.

تنبيه: عند تثبيت نسخة أحدث فوق القديمة قد يرفض الجهاز لاختلاف مفتاح التوقيع المؤقت؛
في هذه الحالة احذف القديمة أولًا (بعد أخذ نسخة احتياطية من **الإعدادات ← تصدير البيانات**).
